# 星汐 Astide

## 核心特性

- **纯正微信 / WeUI 体验**：统一采用腾讯 [WeUI](https://weui.io/) 设计规范，包含四标签底部导航（星汐 / 通讯录 / 发现 / 我）、微信朋友圈（支持 AI 自主发动态、互相点赞与评论互动）、聊天列表左滑置顶/删除、逆向虚拟列表长会话零跳动加载、带尖角绿色/白色聊天气泡、无边框圆角图片消息、微信风格文件卡片、折叠深度思考（`THINK`）以及简洁可扩展的附件面板，无多余占位按钮。
- **全本地 SQLite 存储（免登录）**：所有会话、消息、附件、人物设定、API 配置与个人信息全部存储在本地 `astide.db` 中。
- **置顶星汐 & 一句话 AI 创建人物**：
  - 默认强制置顶「星汐（Astide）」以真实人类身份陪伴聊天，不自称 AI；
  - 支持输入一句话或粘贴整段提示词由 AI 自动阅读并填写整张人物表单，也可手动精细定制人物姓名、身份、关系、性格、背景、口癖、开场白；支持仿微信连续发送多条短气泡。
- **自主意识与 Android 常驻后台**：
  - 支持开启 Android 前台守护服务常驻后台，AI 可根据当前时间与聊天上下文自主判断是否主动向你发微信消息并弹出系统通知；
  - 当会话较长时，在后台静默压缩早期记忆摘要并持久化到本地 SQLite，无任何提示干扰。
- **OpenAI 兼容接口 & 多模态附件**：
  - 预设最新 DeepSeek 官方接口（`deepseek-flash` / `deepseek-v4-pro`），支持 `deepseek-flash` 原生图像理解、Thinking 思考模式切换、`/models` 模型列表拉取及流式输出；
  - 聊天支持发送相册图片、相机拍摄与多种文件（`.txt`、`.md`、`.json`、`.csv`、`.pdf`、`.docx`、`.xlsx`、`.pptx` 及常见代码文件），自动在本地提取文档文本随消息发送给模型。
- **DeepSeek 官方历史记录导入**：
  - 支持直接粘贴 DeepSeek 官方导出 `.zip` 下载链接或选择本地 `.zip` 文件导入，完整解析分支会话（`parent_id` / `current_message_id`）、`THINK` 思考过程、图片附件（`.webp`）及文件记录，支持按原上下文继续聊天。
