# 星汐 Astide

## 核心特性

- **纯正微信 / WeUI 体验**：统一采用腾讯 [WeUI](https://weui.io/) 设计规范，包含四标签底部导航（星汐 / 通讯录 / 发现 / 我）、微信朋友圈（支持 AI 自主发动态、互相点赞与评论互动）、聊天列表左滑置顶/删除、聊天内点击头像打开对方主页与双击轻震动「拍一拍」、逆向虚拟列表长会话零跳动加载、带尖角绿色/白色聊天气泡、无边框圆角图片消息、微信风格文件卡片与折叠深度思考（`THINK`）。
- **全本地 SQLite 存储与多格式导出（免登录）**：所有会话、消息、附件、人物设定、API 配置与个人信息全部存储在本地 `astide.db` 中；支持将单条或全部会话导出为 **SQLite（`.sqlite`）、XML（`.xml`）、JSON（`.json`）、纯文本（`.txt`）、Markdown（`.md`）与离线网页（`.html`）**，导出文件自动过滤敏感 API Key。
- **置顶星汐 & 一句话 AI 创建人物**：
  - 默认强制置顶「星汐（Astide）」以真实人类身份陪伴聊天，不自称 AI；
  - 支持输入一句话或粘贴整段提示词由 AI 自动阅读并填写整张人物表单，也可手动精细定制人物姓名、身份、关系、性格、背景、口癖、开场白；支持基于多次独立请求实现真实的微信连续短气泡回复。
- **概率自主意识与 Android 常驻后台**：
  - 支持开启 Android 前台守护服务常驻后台，AI 会按可配置的概率与间隔结合当前时间及上下文自主判断是否主动发微信或回应「拍一拍」，并弹出系统通知；
  - 当会话较长时，在后台静默压缩早期记忆摘要并持久化到本地 SQLite，无任何提示干扰。
- **OpenAI 兼容接口 & 多模态附件**：
  - 默认预设最新 DeepSeek V4.1 Flash（`deepseek-flash`），支持原生图像理解、Thinking 思考模式切换、`/models` 模型列表拉取及流式输出，并兼容自定义 OpenAI 格式接口；
  - 聊天支持发送相册图片、相机拍摄与多种文件（`.txt`、`.md`、`.json`、`.csv`、`.pdf`、`.docx`、`.xlsx`、`.pptx` 及常见代码文件），自动在本地提取文档文本随消息发送给模型。
- **DeepSeek 官方历史记录导入**：
  - 支持直接粘贴 DeepSeek 官方导出 `.zip` 下载链接或选择本地 `.zip` 文件导入，完整解析分支会话（`parent_id` / `current_message_id`）、`THINK` 思考过程、图片附件（`.webp`）及文件记录，支持按原上下文继续聊天。
