## 二、小红书正文文案（可直接复制发布）

最近 DeepSeek 官方客户端聊天受限后，好多姐妹/兄弟担心自己养了很久的长对话、角色和深度思考记忆没法接着聊😭。

其实完全不用慌——我开发并开源了一个**纯本地 AI 伴聊工具「星汐 Astide」**（Android，基于 WeUI 微信设计规范 + GNU AGPL-3.0 开源），不仅界面高仿微信，**还直接支持把 DeepSeek 官方客户端的聊天数据无损导进来，接上自己的 Key 原地续聊！** 👇

### ✨ 核心特色功能拆解

1️⃣ **官方受限无缝接管：一键导入 DeepSeek 官方历史记录**
- 在 DeepSeek 官方 App / 网页端「设置 → 隐私与数据 → 导出数据」拿到下载链接或 `.zip` 压缩包，打开星汐直接**粘贴 URL 下载或选本地压缩包导入**；
- 完整解析多分支对话树、`THINK` 深度思考链、时间线与 WebP 图片附件，防重增量写入本地 SQLite——老记忆不断档，顺着原上下文继续聊！

2️⃣ **纯正微信视觉 + 多次请求真连发（不是竖线硬切）**
- 告别网页版“AI味”长段套壳框，左滑置顶/删除、气泡尖角、逆向列表加载长对话不跳动，界面干净无冗余；
- 抛弃“模型先吐一大堆再用 `|` 强制切割”的不稳定老方案，改成**多次独立请求连续追发**，像真人在微信上打字那样一句一句发过来！

3️⃣ **点头像进主页 · 双击头像轻震“拍一拍”**
- 聊天中**轻点对方头像**打开 Ta 的微信主页（浏览人设资料 & Ta 的朋友圈）；
- **双击对方头像会伴随手机轻轻震动**，弹出“你拍了拍某某”，AI 还会按设定概率冒泡回应甚至反手回拍你！

4️⃣ **TA 有自己的生活时间：AI 自发朋友圈 + 按概率主动联系**
- “发现”页即纯粹**微信朋友圈**：角色按冷静节制节奏发文字/自绘 SVG 配图动态，且**聊天上下文与朋友圈记忆互通**，私聊聊起完全接得上；
- 开启后台常驻守护后，AI 不是定时机械闹钟，而是结合时段、沉默时长与你设定的**触发概率**（夜间 `00:00–07:00` 自动免打扰）随机决定要不要主动发微信弹通知找你。

5️⃣ **一句话 AI 捏人 + 6 种格式导出备份，数据完全属于你**
- 输入一句脑洞或贴入超长 Prompt，AI 自动填好全套人设表单；
- 无登录、无云端留存！随时把单个或全部对话一键导出为 **`.sqlite` / `.xml` / `.json` / `.txt` / `.md` / 离线 `.html`**（自动剥离 API Key），再也不怕任何平台受限丢记录 🔒。
